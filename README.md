# Bildschema

Bildstöd för dag- och kvällsrutiner för ett litet barn, med belöning. Statisk webbapp (inga beroenden), fungerar offline och kan läggas på hemskärmen. Allt sparas lokalt i webbläsaren.

- **Ikväll:** bad, tänder, smörjning, pyjamas och säng, och sedan morgondagens schema. Barnet trycker på sin ruta (tassen) och en vuxen godkänner genom att hålla in hjärtat. Därefter görs morgondagens schema, djuret nattas och ett klistermärke sätts in i samlarboken. Sist spelas en vaggvisa medan skärmen sakta blir mörk.
- **Idag:** schemat ni gjorde kvällen innan.
- **Samlarbok:** 7 klistermärken fyller en sida och låser upp ett nytt djur att natta.
- Håll in ⚙️ för inställningar.
